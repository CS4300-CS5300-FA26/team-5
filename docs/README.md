Notes for the five of us while we build Binge & Bosses: how the project is laid out and how our tools work. The top-level [README](../README.md) covers installing and running the project. These pages cover the rest.

| Page | Read it when |

| [Pull requests](pull-requests.md) | You're about to open a PR, or you're wondering why a check failed |
| [Testing](testing.md) | You're writing tests or coverage dropped below 80% |
| [Deployment](deployment.md) | You want to know how code gets to the live site |

## Rules for this folder
- **The repo is public.** Anyone on the internet can read these pages. Never put keys, passwords, `.env` contents, or production URLs with credentials here.
- **Keep pages short.** If a page needs scrolling to find the point, split it.
- **Fix what's wrong.** If you follow a page and it doesn't match what happened, update it in your PR. Out-of-date docs are worse than none.
- **Explain why, not just what.** "We do X because Y" helps the next person decide when X doesn't apply.
- **Add new pages to the table above.**
